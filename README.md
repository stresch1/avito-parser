# Парсинг Авито — локальное веб-приложение

## Запуск

Двойной клик по `run.bat` — откроется браузер на http://127.0.0.1:8000

Если `run.bat` не работает, вручную:
```
cd AvitoParser
venv\Scripts\activate
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## Как пользоваться

1. Вставьте одну или несколько ссылок на выдачу Avito (раздел «Грузовики и спецтехника»
   целиком или конкретная подкатегория/поиск — любая ссылка вида
   `https://www.avito.ru/.../gruzoviki_i_spetstehnika/...`).
2. При необходимости ограничьте число объявлений на ссылку (0 = без лимита).
3. Настройте колонки выгрузки (по умолчанию — все 48, как в ваших исходных файлах).
4. Нажмите «Запустить парсинг». Задача появится в списке справа и будет обновляться в реальном времени.
5. По готовности — кнопка «Скачать» рядом с задачей.

## Прокси

Avito блокирует IP при активном сборе. Когда купите прокси, вставьте их в поле
«Настройки прокси» построчно в формате:
```
host:port:login:pass
```
или без авторизации:
```
host:port
```
Парсер будет распределять запросы между прокси по кругу (round-robin), новый контекст
браузера — новый прокси.

## Ограничения текущей версии

- Реализован только «Полный парсинг» (заход на каждое объявление). Быстрый режим
  «только продавцы» не реализован — при необходимости расширим.
- Расписание и отправка на email не реализованы — только ручной запуск и скачивание файла.
- «Только из выбранного региона» пока сохраняется как настройка задачи, но не фильтрует
  результаты — довнедрим при необходимости.
- Селекторы вёрстки Avito основаны на атрибутах `data-marker`. Avito периодически меняет
  структуру страниц — если парсинг перестал находить поля (много пустых колонок),
  разбор в `app/scraper.py` нужно будет актуализировать под новую вёрстку.
- Без прокси на большом объёме объявлений Avito может временно заблокировать IP —
  парсер делает паузы между запросами, но это не гарантия от бана.

## Структура проекта

- `app/main.py` — FastAPI-сервер и API
- `app/scraper.py` — логика сбора данных с Avito (Playwright)
- `app/exporter.py` — выгрузка в Excel (openpyxl)
- `app/db.py` — история задач (SQLite, `data/db/tasks.sqlite3`)
- `app/columns.py` — схема из 48 колонок выгрузки
- `app/static/` — веб-интерфейс
- `data/exports/` — готовые Excel-файлы
- `data/proxies.txt` — список прокси
