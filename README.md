# AvitoParser

Готовое Windows-приложение для сбора объявлений с Avito и выгрузки результата в Excel. Приложение запускается локально, открывает веб-интерфейс в браузере и позволяет запускать задачи парсинга без ручной работы с Python-консолью.

## Что умеет приложение

- Принимает одну или несколько ссылок на выдачу Avito.
- Собирает данные по объявлениям в режиме полного парсинга.
- Поддерживает настройку списка колонок для итоговой таблицы.
- Сохраняет историю задач локально.
- Показывает прогресс выполнения в веб-интерфейсе.
- Формирует Excel-файл, который можно скачать после завершения задачи.
- Поддерживает прокси в формате `host:port` или `host:port:login:pass`.
- Может использовать сервис распознавания капчи, если указан ключ.

## Скачать готовое приложение

Готовый архив приложения опубликован в разделе **Releases** этого репозитория:

https://github.com/stresch1/avito-parser/releases

Прямая ссылка на текущую сборку:

https://github.com/stresch1/avito-parser/releases/download/v1.0.0/AvitoParser.zip

Скачайте `AvitoParser.zip`, распакуйте архив, запустите `AvitoParser.exe` двойным кликом и дождитесь открытия локального интерфейса в браузере.

Важно: ключи, прокси, база задач и Excel-выгрузки не входят в репозиторий. Они хранятся локально на компьютере пользователя.

## Как пользоваться

1. Откройте приложение.
2. Вставьте одну или несколько ссылок Avito.
3. Укажите лимит объявлений, если нужно ограничить объем.
4. Выберите нужные колонки выгрузки.
5. При необходимости добавьте прокси.
6. Нажмите запуск парсинга.
7. После завершения скачайте Excel-файл из интерфейса.

## Прокси и капча

Avito может ограничивать частые запросы. Для стабильной работы на больших объемах рекомендуется использовать прокси.

Также для обхода капчи используются cookie с сайта `spfa.ru`.

Форматы прокси:

```text
host:port
host:port:login:pass
```
